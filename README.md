# CIT Question Papers

An open-source archive of examination question papers from **Cambridge Institute of Technology, Tatisilwai, Ranchi**.

The goal of this project is to preserve past question papers and make them easily accessible to current and future students.

## Current Scope

The repository currently contains question papers for:

- **Branch:** Computer Science and Engineering (CSE)
- **Examinations:** Mid-Semester and End-Semester
- **Format:** PDF
- **Academic years:** From the 2026-27 batch onward

More branches will be added in the future.

## Repository Structure

```text
CSE/
├── 1st-Semester/
├── 2nd-Semester/
├── 3rd-Semester/
├── 4th-Semester/
├── 5th-Semester/
├── 6th-Semester/
├── 7th-Semester/
└── 8th-Semester/
```

Each semester contains subjects, which are further divided into examination types:

```text
Subject/
├── Mid-Sem/
└── End-Sem/
```

## Contributing

If you have a question paper that is not already available in the repository, you can contribute it.

Please read [CONTRIBUTING.md](CONTRIBUTING.md) before submitting a paper.

## Purpose

This project is intended to preserve academic question papers for the benefit of students and future batches.

If you are a CIT student and have papers that are missing from the archive, consider contributing them.
