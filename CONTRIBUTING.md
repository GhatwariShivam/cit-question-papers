# Contributing to CIT Question Papers

Thank you for helping preserve examination question papers from Cambridge Institute of Technology.

This repository is maintained to make past question papers easily accessible to current and future students.

## What You Can Contribute

You can contribute:

- Mid-Semester examination question papers
- End-Semester examination question papers

Currently, we accept **PDF files only**.

## Before Contributing

Please make sure that:

1. The paper is from Cambridge Institute of Technology.
2. The paper belongs to the CSE branch.
3. The paper is not already available in the repository.
4. The paper is clear and readable.
5. The paper does not contain unnecessary personal information.
6. You place the paper in the correct folder.

## File Structure

Follow this structure:

```text
CSE/
└── Semester/
    └── Subject/
        ├── Mid-Sem/
        └── End-Sem/
```

For example:

```text
CSE/
└── 5th-Semester/
    └── Database-Management-Systems/
        └── Mid-Sem/
            └── 2026-27.pdf
```

## File Naming

Name question papers using their academic year:

```text
2026-27.pdf
2027-28.pdf
```

If there are multiple papers for the same subject and examination in the same academic year, use:

```text
2026-27-Set-A.pdf
2026-27-Set-B.pdf
```

## How to Contribute

All contributions must be submitted through a **Pull Request**.

1. Fork this repository.
2. Add the question paper to the correct folder.
3. Make sure the file follows the naming and folder structure described above.
4. Create a Pull Request.
5. Provide a short description of the paper you are adding.
6. Wait for the paper to be reviewed.

The maintainer may request changes before the Pull Request is merged.

## Review

Every contribution will be reviewed before being added to the main repository.

A contribution may be rejected if:

- The paper is unrelated to the project.
- The paper is a duplicate.
- The paper is placed in the wrong location.
- The file is not a PDF.
- The paper is unclear or unreadable.
- The contribution contains unnecessary personal information.

Thank you for contributing to the CIT Question Paper Archive!
